# ShareByte
Spring Boot backend for ShareByte – a real-time food redistribution platform connecting restaurants with NGOs.

# ShareByte Backend

ShareByte is a real-time food redistribution platform that connects restaurants with NGOs, orphanages, old-age homes, and ashrams to reduce food waste.

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
